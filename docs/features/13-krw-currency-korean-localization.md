# 13. 원화(KRW) 통화 · 전면 한글화

브랜치: `feature/krw-currency-korean-localization`

## 무엇을 만들었나
- KRW 정수 금액: 시드 가격을 소수 USD식(`89.99`) → 정수 원(`89000`)으로. `format.js`의 `formatCurrency`가 `xx,xxx원`으로 렌더, 전 페이지의 가격 표기 교체. 관리자 가격 입력도 정수(`step=1`).
- 전면 한글화: 모든 클라이언트 페이지의 사용자 노출 텍스트(네비·헤더·버튼·라벨·플레이스홀더·상태 메시지·토스트) 한글로.
- 백엔드 에러 메시지 한글화: 양 스택 `{"error":...}` 문자열, `api.js` 기본 폴백("요청에 실패했습니다 (...)")까지.
- 유지: VULN 문서의 페이로드 예시, `sortKey` 디버그 컬럼, 시드 username/role 등 식별자.
